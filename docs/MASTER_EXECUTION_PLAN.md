# FilmCraft Academy — Master Execution Plan

## Mandate

Deliver a complete local V1, not a demo. Work proceeds through ten auditable phases with curriculum, engineering, learning design, persistence, progression, accessibility, PWA, and release gates.

## Decisions and sequence

1. **Repository audit:** preserve existing material, select a reversible local-first stack, document constraints.
2. **Contracts:** define a canonical Zod curriculum schema, progress state machine, graph, XP curve, storage adapter, and theme tokens.
3. **Curriculum map:** enumerate every domain, cluster, skill, prerequisite, assignment and boss; validate cycles, reachability, cross-links and required-topic coverage before scale writing.
4. **Foundation:** build React/Vite/TypeScript PWA shell, routing, IndexedDB persistence, settings, backup/export/import, and private device access.
5. **Progression:** implement prerequisite evaluation, state transitions, idempotent XP awards, level curve, achievements, titles, specializations, and completion.
6. **Learning:** render complete lessons, checks, exercises, rubrics and evidence. Keep large media external and all learning available without uploads.
7. **RPG interface:** implement all twelve specified views, responsive navigation, interactive pan/zoom trees, accessible motion and milestone feedback.
8. **Content/final boss:** complete all content using controlled templates plus topic-specific concepts, references and practical consequences; implement BEGGIN' FOR FUEL as the final gate.
9. **QA:** run graph/content/unit/build and rendered desktop/mobile/PWA checks; repair failures.
10. **Release:** deliver setup, backup, deployment, authoring, troubleshooting, audit and phase reports.

## Quality gates

Each phase report records artifacts, tests, repairs and risks. `npm run check` is the release gate. No placeholder markers, duplicate IDs, cycles, unreachable required skills, broken references, orphaned assignments, unsupported blocks or double XP awards may remain.
